# Darsh Bhatt

Personal portfolio for data engineering, applied AI, and software engineering.

Live site: https://darsh-008.github.io/Know_Darsh/

## Local preview

No build step or package install is required.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173 in a browser.

## Editing

- `index.html`: profile, experience, work examples, skills, and contact links.
- `styles.css`: responsive layout, colors, typography, and motion.
- `script.js`: navigation, experience links, scroll reveals, and email copying.
- `Resume/Darsh_Resume.pdf`: the resume used by every resume link.
- `img/Darsh_Headshot.jpeg`: profile portrait.

Animations use CSS and the browser's Web Animations API, with no animation
dependencies. They respect reduced-motion preferences. Content and native
experience disclosures remain usable without JavaScript.

## Publishing

The existing GitHub Pages setup publishes the `main` branch. Check the Pages
deployment after pushing changes. Previous versions are preserved in Git history.
